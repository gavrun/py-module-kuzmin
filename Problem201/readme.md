# tic-tac-toe

A console-based Tic-Tac-Toe game between a human player (`O`) and the computer (`X`).

* 3x3 board display with numbered squares
* Player uses numbers (1–9) to make a move
* Computer chooses moves randomly
* Automatic win/tie detection

* Сomputer makes random valid moves.
* Сomputer always starts with `X` in the center
